# Biblioteca Java

Sistema de gerenciamento de biblioteca desenvolvido em Java.

## Funcionalidades

- Cadastro de livros
- Listagem de livros
- Busca por ID
- Busca por título
- Atualização de livros
- Exclusão de livros

## Tecnologias utilizadas

- Java 26
- Programação Orientada a Objetos
- ArrayList
- Git e GitHub

## Conceitos aplicados

- Classes e objetos
- Encapsulamento
- Métodos
- Collections
- CRUD
- Organização de responsabilidades
